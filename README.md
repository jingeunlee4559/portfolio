## :pushpin: Intro
1. 전기공학을 전공한 뒤 개발자로 방향을 바꿨고, 빅데이터 융합서비스, 언어지능 기반 분석 서비스모델, 앱기반 인공지능(풀스택), AI서비스개발 과정을 차례로 수료했습니다.
</br>
2. 팀 프로젝트 8개에서 React 화면 구현은 물론 UI/UX 설계, Spring Boot·Node.js 기반 REST API, FastAPI 기반 AI 연동까지 맡았습니다.
</br>
3. 문제 정의부터 구조 설계, 구현, 디버깅, 개선까지 책임지며, 로그와 데이터 흐름으로 원인을 추적해 재발을 막는 방식을 선호합니다.
</br>
4. 교육과정 프로젝트로 수상 5회를 기록했습니다.

</br>
